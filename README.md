# Para Camilo

Página estática lista para GitHub Pages. El reproductor usa los archivos locales de Para_Camilo_media; no requiere una API.

## Publicar

1. Sube index.html, esta carpeta y README.md a la raíz de tu repositorio.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, selecciona main y / (root), y guarda.

Conserva la carpeta Para_Camilo_media junto a index.html para que las canciones carguen.
